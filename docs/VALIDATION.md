## 测试覆盖

- 边缘和云端完整路径的手算时延、单位换算和阶段耗时守恒。
- 网络上/下行队列独立、传播不占用带宽、FIFO、多执行槽并行。
- 截止时刻完成、排队取消、执行取消、传播超时及资源即时释放。
- 不同在途阶段的快照回放、源状态不被修改、动态未来任务不可见。
- 空轨迹、预热、窗口 EDF 批量上限、未调度超时、停止生成后的排空。
- 三个优化算法的预算、确定性、最优差距、共同起始解及最佳代价单调性。
- 配置错误、继承循环、基准场景加载与异构总容量守恒。
- 文件损坏重算、原始任务轨迹复用、重放与统计重建。
- 全失败场景的空时延统计、配对 bootstrap、混合任务轨迹拒绝合并。
- Windows 双进程批量运行与单因素趋势图。

## 已生成结果

- `outputs/smoke/analysis/report.md`：36 次开发实验汇总。
- `outputs/smoke/analysis/statistics.csv`：运行均值及 bootstrap 区间。
- `outputs/smoke/analysis/paired_differences.csv`：相同轨迹的算法差值区间。
- `outputs/smoke/analysis/plots/`：静态、动态指标与收敛对比。
- `outputs/exhaustive/optimality_gaps.csv`：六种策略与精确最优值的差距。

在已枚举的种子 0 小算例中，精确最优代价约为 `0.089070985`；GA、ACO、SA 在 100 次评价预算内均达到该值。这只验证该算例，平台不预设任何算法在其他场景下必须胜出。
